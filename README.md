# Путь джуна

Аркадный платформер про карьеру в IT. Маркетинговый проект [workaem.com](https://www.workaem.com):
игра приводит айтишников на сайт, сайт приводит игроков в игру.

**Уровень = грейд.** Стажёр → Джун → Мидл → Сеньор → Лид → Фаундер → Оффер.
Двенадцать уровней, с каждым растёт скорость и добавляются препятствия:
ускорение не искусственное, а смысловое - сеньор просто работает быстрее.

Первый уровень нарисован вручную по методу обучения без слов: восемь коротких
кусков вводят по одной механике за раз - идти, прыгнуть, растоптать, разбить
ящик, перепрыгнуть яму - и ни одной подсказки текстом. Дальше карты собираются
процедурно из кусков, а новые виды кусков открываются каждые два уровня.

Есть подземные уровни (**Серверная**, **Легаси**) со своей палитрой и потолком,
проходные трубы с чёрным жерлом - встал сверху, нажал вниз, вышел из парной,
и финальный собес в конце: три попадания по голове, пока он ходит на тебя,
прыгает и кидает вопросы.

## Стек

- **Vite + TypeScript**, без фреймворка. Canvas-игре React не нужен, а в Mini App
  критична скорость загрузки: сейчас сборка **53 КБ** (18 КБ gzip).
- **Telegram Mini App** - личность игрока приходит бесплатно в `initData`, логина нет.
- Игра работает и вне Telegram: в обычном браузере на стрелках и пробеле.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run typecheck  # tsc в strict-режиме
```

В режиме разработки `?level=12` стартует с нужного уровня - в собранной игре
параметр игнорируется.

### Проверки

Карты собираются процедурно, поэтому глазами их не проверить: сломанное место
может выпасть на одном сиде из десяти. Проверки считают вместо глаз.

```bash
npm run check         # проходима ли геометрия: нет ли непрыгаемых ям
npm run check:blocks  # не мешают ли ящики балкам и друг другу
npm run check:float   # невесомость: без опоры игрок обязан падать
npm run playtest      # автопрохождение настоящей физикой, включая бой с боссом
```

`playtest` пробует шесть стратегий прыжка с постоянной длиной, а если не вышло -
перебирает случайные. Живой игрок перед широкой ямой прыгает во всю силу, а на
мостике из балок делает короткие шаги; ни одна стратегия с постоянной длиной так
не умеет, и уровень, который человек проходит спокойно, числился непроходимым.

## Структура

```
src/
  game/
    types.ts     - типы сущностей
    tuning.ts    - ВСЕ числа баланса в одном месте
    levels.ts    - уровни как данные: добавить уровень = дописать объект
    palette.ts   - единственный источник цвета
    sprites.ts   - пиксель-арт прямоугольниками, переиспользуется вне игры
    world.ts     - состояние и логика
    render.ts    - отрисовка
  platform/
    input.ts     - клавиатура и тач
    telegram.ts  - обёртка над Mini App SDK, молча деградирует вне Telegram
  main.ts        - сборка всего вместе, HUD, финальный экран
```

Уровни намеренно объявлены данными, а не кодом: в такой игре время съедает
контент, а не механика. Новый уровень - это десяток строк в `levels.ts`.

Статика - кладётся куда угодно с HTTPS (Telegram требует HTTPS).
Целевой адрес - поддомен workaem, чтобы расшаренные ссылки вели трафик
на свой домен, а не на чужой.

## Безопасность

⚠️ **Токен бота и ключи - только в переменных окружения, никогда в репозитории.**

Очки, посчитанные на клиенте, подделываются за минуту. На сервер уходит не только
счёт, а состояние забега (`RunStats`: кадры, прыжки, растаптывания, смерти) -
по нему отсекаются невозможные результаты вроде уровня за восемь секунд.
`initData` проверяется HMAC-SHA-256 с ключом, который сам является
HMAC-SHA-256 от токена бота с константой `WebAppData`, плюс проверка срока `auth_date`.
